# Data Directory

The dataset used in this project originates from the Kaggle TRI AI Agricultural Extension RAG Competition.

Due to file size and repository guidelines, raw datasets are not committed directly to this folder.

### Instructions to acquire the data:
1. Access the Kaggle Competition page for the Agricultural RAG Extension.
2. Download `test_queries.csv` and `documents.csv`.
3. Place both CSV files into this `data/` directory before running `scripts/run_pipeline.py`.
